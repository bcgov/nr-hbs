# 11. Who can do what

Your roles decide which areas, screens and buttons you see. Roles stack: you
hold one **base role** that lets you view, plus any number of roles that let
you change things. Industry roles are granted per organization.

## Base roles (viewing)

| Role | For | Can view |
|---|---|---|
| Ministry User | Ministry staff | Every area, including ministry-only screens |
| Industry User | Forest-industry clients | Queries, Scale Returns, Stratum Planner, Rating, Billing, Scale Control and Profiles, for their own organization |
| Other Industry User | Submission agents, software vendors | Scale Returns, for their own organization |

## Ministry roles

| Role | Lets you |
|---|---|
| Ministry User Administrator | Maintain user data domains |
| Ministry User Manager | Maintain user data domains; generate final bills |
| Help Desk | View only (same as Ministry User) |
| Detail Data Entry | Enter and change detail returns; submit XML files; batch slips |
| Ministry Check Scaler | Enter and change detail returns; submit XML files |
| Summary Data Control | Enter and change summary returns, including weight and sample returns; batch slips |
| Summary Data Correction | Summary Data Control, plus cancel and replace invoiced summary returns |
| Scaling Administrator | Scale site profiles, scaler profiles and keys, anomalies, LDS registry, field-scaled decks; enter and change returns; submit XML files |
| Sample Plan Administrator | Change sampling plans, strata, default ratios and population profiles |
| Rate Administrator | Change override rules and rates, and district default rates |
| Waste/Residue Rate Administrator | Change waste and residue rates |
| Billing Administrator | Final bills, mark holder, delivery and cruise-based billing profiles, field-scaled decks, rate correction requests, approving detail return changes, cancel and replace summary returns |
| Invoice Correction Approver | Approve or reject rate corrections and detail return changes |
| Super Manager | Final bills, field-scaled decks, forcing summarization and ratio computation |
| Production Control | Processing parameters, anomaly assessment windows, batch slips |

## Industry roles (per organization)

| Role | Lets you |
|---|---|
| Industry User Administrator | Maintain data domains for your organization's users |
| Industry Site Administrator | Enter and change returns; submit XML files; work anomalies |
| Industry Scaler | Industry Site Administrator, plus scaler profiles and authentication keys |
| Industry Cruise Based Administrator | Enter summary returns; hold or discard cruise-based (area) returns for your marks |
| Industry Sample Plan Administrator | Change your organization's sampling plans |
| Industry Document Receiver | Search statement transmissions across all your associated locations |

## Other industry roles (per organization)

| Role | Lets you |
|---|---|
| Other Industry Administrator | Maintain data domains for your organization's users |
| Data Submission Agent | Enter summary returns; submit XML files |
| Software Vendor | Submit XML files; view scale site software use |
