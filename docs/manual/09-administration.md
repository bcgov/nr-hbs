# 9. Administration

## Who gets access is managed in FAM, not HBS

Requesting access, approving it and granting roles all happen in **FAM
(Forest Access Management)**. HBS has no registration or approval screens.
Contact your organization's FAM administrator, or the ministry for ministry
roles.

## User Data Domains

*User Administrator roles (ministry, industry or other industry).*

A user's **data domains** narrow where their roles apply and set their
default search criteria. There are three kinds:

- **Associated Districts**
- **Associated Sites** (scale sites)
- **Associated Locations** (client locations)

For example, the "Marks in Associated Districts" search option uses a user's
Associated Districts.

1. **Administration › User Data Domains**.
2. Search by user ID (`IDIR\NAME` or `BCEID\NAME`), name, email, user type,
   status, client or organization unit.
3. Open the user. Use **Add Associated District**, **Add Associated Site**
   or **Add Associated Location**, or **Remove** an existing one.

Changes take effect immediately. Industry administrators can only change
users in their own organization.

## Alert and Processing Parameters

*Production Control role.*

**Administration › Harvest Billing System Alert and Processing Parameters**
holds system-wide settings used by the overnight processing, and the alert
message shown on the home page.
